# Example Datasets

Sample files for testing OncoGene Annotator uploads.

| File | Format | Use case |
|------|--------|----------|
| `expression_data.json` | JSON | Full upload with 12 cancer genes × 8 samples. Produces expression stats + annotations. |
| `genes.tsv` | TSV (header + one symbol per line) | Gene-list only. Annotations populated from internal DB; no expression stats. |
| `genes.txt` | Plain text (one symbol per line) | Same as TSV, minimal format. |

Drag any of these files onto the upload area to try the app.
